Guides

How to prepare a drive on a computer so OTG Master can open it, and how to open the app's backups on a computer. You can also encrypt a drive in the app itself: More actions → Encrypt on a mounted drive creates a VeraCrypt or LUKS2 volume.

Every one of these erases the drive or partition you choose. Copy anything you need off it first.

A VeraCrypt drive (Windows, macOS, Linux)

  1. Install VeraCrypt and open it. Choose Create Volume.
  2. Choose Encrypt a non-system partition/drive, then Standard VeraCrypt volume, then select the USB drive or one of its partitions.
  3. Choose Create encrypted volume and format it.
  4. Encryption: AES, Serpent, Twofish and their cascades work; Camellia and Kuznyechik do not. Hash: SHA-512 or Argon2id. SHA-256, Whirlpool and Streebog do not work in the app.
  5. Choose a password. A PIM and keyfiles are optional, and the app takes both.
  6. Filesystem: exFAT for a drive you also use on Windows and macOS, FAT for the widest compatibility (files up to 4 GB), or NTFS. Then format.

VeraCrypt file containers (a .hc file on a drive) do not work: the app opens whole partitions and whole drives only.

A LUKS drive (Linux)

Replace /dev/sdX1 with your drive's partition: check it with lsblk first, because this erases it.

sudo cryptsetup luksFormat --type luks2 /dev/sdX1
sudo cryptsetup open /dev/sdX1 usbcrypt
sudo mkfs.exfat -L MYDRIVE /dev/mapper/usbcrypt     # or mkfs.ext4, mkfs.vfat -F 32, mkfs.ntfs -f
sudo cryptsetup close usbcrypt

cryptsetup's defaults (LUKS2, AES-XTS with a 512-bit key, Argon2id) are what the app expects. LUKS1, PBKDF2 and Argon2i also work. The app refuses other ciphers or key sizes, dm-integrity, and a volume still being re-encrypted, and says which one it found. GNOME Disks makes the same kind of volume: choose Password protect volume (LUKS) when you format.

Argon2id needs memory: a volume made with very high memory settings can be too much for an older phone to unlock.

A BitLocker drive (Windows)

  1. In File Explorer, right-click the USB drive and choose Turn on BitLocker. This needs Windows Pro, Enterprise or Education; Windows Home can open BitLocker drives but not create them.
  2. Choose Use a password to unlock the drive. Smart cards do not work in the app.
  3. Save the recovery key somewhere safe. The app accepts the 48-digit recovery key in place of the password.
  4. Either encryption mode works: compatible mode or new encryption mode.
  5. Let Windows finish encrypting before you unplug the drive. The app does not open a drive that is part-way through encryption.

The drive can hold NTFS, exFAT or FAT32.

The app's backups, on a computer

The app keeps incremental backups in the standard restic repository format, so the free restic tool opens them with the backup's password. (A Plain backup is an ordinary copy in a dated folder, and needs no tool.) The job screen in the app shows the password, and the folder the backups are in.

Install restic, plug in the drive the backups are on (unlocking it on the computer first if it is encrypted), then, with the path to that folder:

restic -r /media/you/MYDRIVE/Backups/phone snapshots                        # list them
restic -r /media/you/MYDRIVE/Backups/phone restore latest --target ~/Restored  # copy the newest back
restic -r /media/you/MYDRIVE/Backups/phone mount ~/mnt                        # browse them (Linux, macOS)

Each command asks for the password. On Windows, restic runs the same way from a command prompt, with a path such as E:\Backups\phone; mount is not available there.
