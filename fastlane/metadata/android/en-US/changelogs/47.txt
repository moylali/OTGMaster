• New: NTFS drives — the format Windows uses — can now be opened, both unencrypted and inside VeraCrypt or LUKS volumes. You can browse, open, create, write, rename, move and delete files on them
• New: BitLocker-encrypted drives can now be unlocked with their password or 48-digit recovery key, and the files on them read and written. Every BitLocker cipher Windows has used is supported (XTS-AES and AES-CBC, 128 and 256 bit, including the Elephant diffuser of Windows 7), as are BitLocker To Go drives and drives whose protection is suspended
• New: An NTFS drive that Windows did not shut down cleanly — left hibernated, saved by Fast Startup, or unplugged without ejecting — opens read-only and says why, so the app cannot overwrite changes Windows has not finished applying
• New: On NTFS, names Windows cannot open (such as CON, or names containing : ? | or a trailing dot) and names differing from an existing file only in upper/lower case are refused, so everything you create stays reachable from Windows
• Known limitation: NTFS files that Windows has compressed can be read but not changed, and files encrypted with Windows EFS cannot be opened. BitLocker drives locked only to a TPM, smart card or startup-key file cannot be unlocked, and a drive Windows is still encrypting or decrypting is refused until it finishes
